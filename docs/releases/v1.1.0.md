# ffScope v1.1.0

解析結果を確認・活用しやすくする機能を追加し、コード全体の整理と高速化を行いました。

## 主な追加

- OpenAI / Claudeに対応したAIアシスタント。利用者がAPIキーを登録し、解析結果を選んで質問できます。Markdown・表・コードブロック表示に対応。
- 納品仕様チェックと総合チェック。解像度・fps・コーデック・音声・ラウドネスなどの条件を確認し、未測定項目は未確認として表示します。
- 前後のフレームとの違いから異常フレーム候補を検出する機能。
- コンタクトシートとビットレートグラフの拡大表示。フレーム保存はJPG / PNG / TIFFに対応（コンタクトシート）。
- Classic / Liquid Glass / Obsidian / Dot Matrixのテーマと、独立したダーク・ライト切り替え。
- GitHub Releases経由のアプリ内更新。更新パッケージの署名検証、進捗表示、利用者の確認後の適用に対応。

## 改善・修正

- 未表示タブの初期化を遅延し、表示後の解析はタブを移動しても継続。
- 同じ条件の解析の重複実行を抑制。ファイルの選び直し後に古い解析結果が戻る競合を防止。
- サムネイルの並列生成と容量制限付きキャッシュ。シーク時に不要になったプレビューの生成を削減。
- ビットレート解析の読み取り処理とメモリ使用量を改善。
- MP4のBフレームによるPTSの前後や先頭の負のDTSを、タイムスタンプ異常として扱わないよう修正。
- スライダー、解析結果、拡大ビュー、進捗表示のUIを調整。
- Windowsでの静的チェック警告と、性能測定スクリプトの改行処理を修正。

## ダウンロード

| 対象 | ファイル | 用途 |
| --- | --- | --- |
| macOS Apple Silicon | `ffScope_v1.1.0_macos_arm64.dmg` | アプリをApplicationsへコピー |
| Windows x64 | `ffScope_v1.1.0_windows_x64.zip` | 展開して`ffScope.exe`を起動するポータブル版 |
| Windows x64 | `ffScope_v1.1.0_windows_x64_setup.exe` | アプリ内更新に対応したセットアップ版 |

いずれもffmpeg / ffprobeを同梱します。WindowsはWebView2ランタイムが必要です。
macOS Intel・Linux向けの配布物は含まれません。

## 更新について

「設定 → 更新 → 更新を確認」から安定版を確認できます。初回はこの更新対応版を手動インストールしてください。
Windowsポータブル版はZIPによる手動更新です。`latest.json`、`.app.tar.gz`、`.sig`は自動更新用です。
AI機能のAPI利用料金は利用者のアカウントに発生します。

## 確認状況

- macOSおよびWindowsで自動テスト61件を通過。
- Windowsで通常デスクトップの起動・応答、WebView2プロセスを確認。
- 720p合成動画のサムネイル12枚生成は、macOSで約46%、Windowsで約58%短縮。条件によって効果は変わります。
- 全UI操作、実クラウドAPI、セットアップのインストール、GitHub更新の実適用は未確認です。

異常フレーム検出は候補の抽出です。編集内容や意図的なエフェクトを含め、結果は目視確認してください。
